# 거리측정 (Distance Meter PWA)

폰 카메라와 센서만으로 **수평거리 · 사거리 · 높이차(m) · 경사도(%)**를 측정하는 단독 앱입니다.
측정 대상의 치수를 몰라도 쓸 수 있도록 설계했습니다. 안드로이드(갤럭시) Chrome 기준이며, APK로 설치할 수 있습니다.

> 참고용 측정값입니다. 공식 수치는 줄자·측량기기로 확인하십시오.

## AR 측정(10 m 내외 권장·가장 정확)

Chrome의 WebXR(내부적으로 ARCore)로 지면·벽 등 표면을 인식해 두 점 사이를 잽니다.

| B 지정 방식 | 용도 |
|---|---|
| 표면 점 | A에서 B까지 걸어가며 지면을 계속 비춘 뒤 지정. 수평거리·사거리·높이차·경사도 |
| A 위 높이 | A 바로 위(벽·댐·나무 끝)를 조준. 표면이 없어도 연직 높이를 잰다 |

- ARCore 지원 기기와 Chrome이 필요합니다(갤럭시 대부분 지원). 미지원 기기에서는 센서 방식을 사용합니다.
- 브라우저 AR 제약으로 AR 측정은 카메라 사진을 기록하지 않습니다.

## 센서 측정 방식(먼 거리·AR 미지원 시)

| 방식 | 조준 순서 | 필요한 값 | 계산식 |
|---|---|---|---|
| 높이·거리(기본) | 기저부 → 상단(선택) | 카메라 높이 h, 지면 경사 β(선택) | `D = h / (tan β − tan α₁)` |
| 이동 측정 | 같은 지점을 두 위치에서 | 이동 거리 b(걸음 수 환산 가능) | `D = b·tan α₁ / (tan α₂ − tan α₁)` |
| 폭·간격 | A 기저부 → B 기저부 | 카메라 높이 h | `W = √(D_A² + D_B² − 2·D_A·D_B·cos Δψ)` |
| 기준 높이법(기타) | 기준물 하단 → 상단 | 기준물 높이 H | `D = H / (tan α₂ − tan α₁)` |
| 거리 입력법(기타) | 지점 1개 이상 | 수평거리 D | — |

- 사거리 `S = D / cos α`, 높이차 `Δh = D·(tan αᵢ − tan α₁)`, 경사도 `G = (관측자 발밑 → 마지막 지점 높이차) / D × 100 %`
- α: 카메라 광축 앙각(기울기 센서), Δψ: 두 조준 사이 수평 회전각(자이로 센서)
- 지면 경사 β: 폰을 지면에 눕혀 윗변이 표적을 향하게 두면 자동으로 읽습니다.

## 폰 센서만으로 정확도를 높이는 기능

- **카메라 높이 보정**: 한 번만 줄자로 5~10 m를 재고 바닥을 조준하면 평소 자세의 카메라 높이를 역산해 저장합니다.
- **지면 경사 보정**: 경사지에서 평지 가정으로 생기는 큰 오차를 줄입니다.
- **자동 촬영**: 조준이 1.2초 안정되면 버튼 없이 촬영해 누를 때의 흔들림을 없앱니다.
- **줌**: 기기가 지원하면 줌 슬라이더로 먼 기저부를 정확히 조준합니다.
- **사진 탭 보정**: 촬영 후 사진을 탭해 조준점을 옮기면 앙각이 보정됩니다(줌 배율 반영).
- **오차 범위**: 앙각 ±0.5°(설정 가능)를 가정한 결과의 ± 범위를 함께 표시합니다.
- **영점 보정**: 수평면에 폰을 놓아 센서 치우침을 보정합니다.

## 기록

- 측정 결과는 조준점·수치를 합성한 사진과 함께 기기 안(IndexedDB)에 저장됩니다.
- 「기록」 탭에서 사진을 크게 보기(탭하면 원본 크기), 저장(다운로드 폴더·갤러리), 공유(카카오톡·메일 등)할 수 있습니다.
- CSV로 전체 기록을 내보낼 수 있습니다.
- 브라우저 데이터를 지우면 기록도 삭제되므로 필요한 기록은 내보내 두십시오.

## 설치형 앱(APK)

`android/`는 웹앱을 Chrome으로 전체 화면에 여는 설치형 껍데기(TWA)입니다. Chrome 안에서 동작하므로 카메라·센서·AR을 그대로 씁니다.

1. 아래 「배포(Vercel)」로 웹앱 주소를 먼저 만듭니다.
2. `android/gradle.properties`의 `twaHost`를 그 주소(https:// 없이)로 바꿉니다.
3. 푸시하면 GitHub Actions 「거리측정 APK 빌드」가 APK를 만듭니다. 실행 결과의 Artifacts(또는 main 브랜치의 Releases)에서 내려받습니다.
4. 폰에서 APK를 열어 설치합니다(「출처를 알 수 없는 앱」 허용 필요).

**고정 서명 키(권장)**: 키가 없으면 빌드마다 임시 키로 서명되어, 새 APK를 설치할 때 이전 앱을 지워야 하고 상단에 주소창이 보입니다. 기록은 Chrome 저장소에 있으므로 앱을 지워도 남습니다.

```bash
keytool -genkeypair -v -keystore release.keystore -alias distance-meter -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.keystore   # 결과를 Secrets의 TWA_KEYSTORE_BASE64로 등록
```

저장소 Settings → Secrets and variables → Actions에 `TWA_KEYSTORE_BASE64`, `TWA_KEYSTORE_PASSWORD`를 등록합니다. 이후 빌드 결과의 `assetlinks.json`을 `public/.well-known/assetlinks.json`에 넣고 웹앱을 다시 배포하면 주소창이 사라집니다. 키 파일은 저장소에 올리지 마십시오(공개 저장소).

## 배포(Vercel)

이 폴더는 저장소 안의 독립 프로젝트입니다.

1. Vercel 대시보드 → **Add New → Project** → 이 저장소 **Import**
2. **Root Directory**를 `distance-meter`로 지정(Framework: Vite 자동 감지)
3. **Deploy**
4. 폰 Chrome으로 주소 접속 → **⋮ → 앱 설치(홈 화면에 추가)**

HTTPS 주소에서만 카메라·센서가 동작합니다.
