# 거리측정 (Distance Meter PWA)

폰 카메라와 기울기 센서만으로 **수평거리 · 사거리 · 높이차 · 두 지점 간격**을 측정하는 단독 앱입니다.
측정 대상의 치수를 몰라도 쓸 수 있도록 설계했습니다. 안드로이드(갤럭시) Chrome 기준으로 만들었습니다.

> 참고용 측정값입니다. 공식 수치는 줄자·측량기기로 확인하십시오.

## 측정 방식

| 방식 | 조준 순서 | 필요한 값 | 계산식 |
|---|---|---|---|
| 높이·거리(기본) | 기저부 → 상단(선택) | 카메라 높이 h, 지면 경사 β(선택) | `D = h / (tan β − tan α₁)` |
| 이동 측정 | 같은 지점을 두 위치에서 | 이동 거리 b(걸음 수 환산 가능) | `D = b·tan α₁ / (tan α₂ − tan α₁)` |
| 폭·간격 | A 기저부 → B 기저부 | 카메라 높이 h | `W = √(D_A² + D_B² − 2·D_A·D_B·cos Δψ)` |
| 기준 높이법(기타) | 기준물 하단 → 상단 | 기준물 높이 H | `D = H / (tan α₂ − tan α₁)` |
| 거리 입력법(기타) | 지점 1개 이상 | 수평거리 D | — |

- 사거리 `S = D / cos α`, 높이차 `Δh = D·(tan αᵢ − tan α₁)`, 경사도 `G = (관측자 발밑 → 마지막 지점 높이차) / D × 100 %`
- α: 카메라 광축 앙각(기울기 센서), Δψ: 두 조준 사이 수평 회전각(자이로 센서)
- 지면 경사 β: 폰을 지면에 눕혀 윗변이 표적을 향하게 두면 자동으로 읽습니다.

## 폰 센서만으로 정확도를 높이는 기능

- **카메라 높이 보정**: 한 번만 줄자로 5~10 m를 재고 바닥을 조준하면 평소 자세의 카메라 높이를 역산해 저장합니다.
- **지면 경사 보정**: 경사지에서 평지 가정으로 생기는 큰 오차를 줄입니다.
- **자동 촬영**: 조준이 1.2초 안정되면 버튼 없이 촬영해 누를 때의 흔들림을 없앱니다.
- **줌**: 기기가 지원하면 줌 슬라이더로 먼 기저부를 정확히 조준합니다.
- **사진 탭 보정**: 촬영 후 사진을 탭해 조준점을 옮기면 앙각이 보정됩니다(줌 배율 반영).
- **오차 범위**: 앙각 ±0.5°(설정 가능)를 가정한 결과의 ± 범위를 함께 표시합니다.
- **영점 보정**: 수평면에 폰을 놓아 센서 치우침을 보정합니다.

## 기록

- 측정 결과는 조준점·수치를 합성한 사진과 함께 기기 안(IndexedDB)에 저장됩니다.
- 「기록」 탭에서 사진을 크게 보기(탭하면 원본 크기), 저장(다운로드 폴더·갤러리), 공유(카카오톡·메일 등)할 수 있습니다.
- CSV로 전체 기록을 내보낼 수 있습니다.
- 브라우저 데이터를 지우면 기록도 삭제되므로 필요한 기록은 내보내 두십시오.

## 배포(Vercel)

이 폴더는 저장소 안의 독립 프로젝트입니다.

1. Vercel 대시보드 → **Add New → Project** → 이 저장소 **Import**
2. **Root Directory**를 `distance-meter`로 지정(Framework: Vite 자동 감지)
3. **Deploy**
4. 폰 Chrome으로 주소 접속 → **⋮ → 앱 설치(홈 화면에 추가)**

HTTPS 주소에서만 카메라·센서가 동작합니다.

## 로컬 개발

```bash
cd distance-meter
npm install
npm run dev      # http://localhost:5173
npm test         # 기하 연산 테스트
npm run build
```
